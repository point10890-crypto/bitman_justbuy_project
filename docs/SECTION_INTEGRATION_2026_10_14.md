# 홈 검색기 재사용 범위와 적용

사용자 요청: 인계 내용을 검토해 기존 앱에 붙일 수 있는 부분을 적용한다. 기존 카드 디자인과 운영 후보 원천은 유지한다.

## 운영 앱에 연결

`ConditionLiquidityService`가 이미 확인하는 KIS 일봉 응답을 재사용한다. 추가 네트워크 호출 없이 `ConditionTechnicalEvidence`가 아래 항목을 계산하고 기존 `conditionChecks`에 연결한다.

- 단타: 누적 거래량 / 직전 완료 20거래일 평균(2배 기준), 전일 고가와 당일 시가 동시 돌파, 전일 종가 대비 3~15%.
- 스윙: 직전 완료 일봉의 5>20>60 이동평균, 전일 20일선 ±2% 접촉 후 당일 양봉·전일 종가 위 반등, 직전 5일 거래량 축소와 당일 누적 회복.
- 종가매매: 15:40 이후 확인한 종가가 당일 고가의 97% 이상인지, 전일 종가 대비 5~15%.

각 항목은 수치·출처·조회 시각과 PASS/FAIL/UNKNOWN을 갖는다. 재조회 판정은 최초 편입 당시 판정과 구분한다. 잘못된 OHLC, 누락된 거래일/거래량, 부족한 과거 기간은 통과시키지 않는다. 누적 거래량 비교는 같은 시각 거래량 비교가 아니다.

주도주 상대강도·업종 순위·52주 고가, 테마 연결, VWAP·체결강도·장중 수급·공시·재무는 이 일봉 계산으로 확인할 수 없으므로 기존 상태를 유지한다. 종목 순위, 포착가, AI 점수, 목표가, 매수 경로를 변경하지 않는다. 이 작업은 검출력 우위를 입증하거나 새로운 검출 원천을 활성화하는 작업이 아니다.

## 그림자 검색기에 적용

- 절대 거래대금 기준을 `ConditionLiquidityPolicy`와 맞춤: 단타/테마 100억(9시 30억, 10시 50억), 스윙 평균 50억, 주도주 평균 200억 + 누적 500억(9시 150억, 10시 250억), 종가 100억.
- 평균은 20일 자료를 모두 요구한다. 단, 엔진의 기존 `Panel.value`는 **종가×거래량 추정치**다. `average_turnover_basis=CLOSE_TIMES_VOLUME_ESTIMATE`, 가정 곡선 `pace_basis=ASSUMED_INTRADAY_CURVE`, `publication_eligible=false`를 표시한다. 운영의 실제 거래대금 통과를 대체하지 않는다.
- 4분기 미만 재무는 미확인·0점. 미확인과 적자는 구분한다.
- 업종 동반 상승 후보는 2개에서 자르지 않는다. 업종 거래대금 순위를 표시하고 뉴스·공시 기반 테마 연결은 UNKNOWN으로 남긴다.
- 전일 날짜 시세는 개별 종목 단위로 제외한다.
- 성과는 `SCAN_SAMPLED_AFTER_CAPTURE`: 포착 후 스캔에서 관측한 가격의 최대값이다. 일중 실제 최고가나 포착 전 고가가 아니다. 스윙의 여러 날 성과 측정은 별도 작업으로 남는다.

## 검증 자료

- `backend/src/test/resources/condition/panocean-kis-20261014.csv`: 2026-10-14 KIS 읽기 전용 커넥터 `kis_get_daily_ohlcv`의 실제 응답에서 추출한 팬오션(028670) 수정 일봉 120개. 요청 symbol=028670, end_date=20261014. 표의 쉼표만 제거해 CSV로 정규화했으며, 원본 HTTP JSON fixture라고 주장하지 않는다.
- 이 자료의 10/14 종가 7,230, 전일 고가 6,630, 당일 시가 6,600, 전일 종가 6,550으로 돌파와 +10.38%를 확인한다. 수익률 우위 검증 자료는 아니다.
- 합성 수치 테스트는 경계/누락/오류 처리의 단위 테스트이며 실제 검출 성과로 사용하지 않는다.
- 운영 전환 플래그 `bitman.engine.sections.enabled=false`는 유지한다. 반려된 `/engine/sections`를 활성화하지 않는다.

## 적용 확인

- 엔진 전체 테스트: 102 통과. 백엔드 전체: 1,252개 중 1,251 통과, 환경 의존 `ResearchRunStoreTest` 1개 제외, 실패 0.
- `scripts/deploy-minipc.ps1`로 프론트 빌드, 백엔드 테스트, JAR 배포 완료. 프론트 소스/번들은 변경하지 않았다.
- 그림자 엔진은 원격 기존 소스가 HEAD와 줄바꿈을 제외하고 일치함을 확인한 뒤 `live_screeners.py` 하나만 백업·교체했다. `var`, DB, 설정과 스케줄은 유지했다.
- 임시 엔진 배포 스크립트의 localhost 상태 확인 대기가 길어져 해당 확인 프로세스만 종료했다. 이후 IPv4 루프백에서 직접 재확인: 엔진 ready, 리스너 1개, 배포 파일 SHA256 일치, 새 성과/추정값 메타데이터와 publication_eligible=false 확인. API 내부/공개 health 모두 ok.
- 운영 홈 DOM 확인: 단타 팬오션 거래량 5.14배·돌파·+10.38% 통과, 스윙 HMM 거래량 축소 미충족, 종가 팬오션 고가 대비 98.10% 통과. HMM 60일 정배열은 자료가 불완전해 UNKNOWN 유지.
- 장 마감 후 배포이므로 새 장중 스캔의 실제 후보 전체 재검증 및 기존 방식 대비 성과 우위는 확인하지 않았다.
