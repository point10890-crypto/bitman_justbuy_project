# 홈 후보 누락 개선과 포착 데이터 수집 — 2026-10-14

이번 변경은 운영 후보 수집·선별 경로를 수정한다. 앞선 `research/section_intent_20261014` 비교에서 성과가 악화된 복합 기술 필터는 적용하지 않는다.

## 적용한 검출 변경

- 단타: 실제 KIS 거래금액순 목록을 거래량·상승률·외국인 순매수 원천에 추가한다. 거래대금 신규 후보 중 +3~15%는 기존 주식수 거래량 점수만으로 사전 탈락시키지 않고, 실제 거래대금 확인과 기존 위험 검증으로 넘긴다. ETF/ETN 제외는 유지한다.
- 단타: 후보 전체를 거래대금 확인에 전달하고 적격 상위 6개를 검증한 후 3개를 게시한다. 기존에는 3개를 먼저 잘라 검증에서 탈락하면 다음 후보를 채울 수 없었다. 포착가는 게시한 종목에 대해서만 최초 확정한다.
- 스윙·테마·주도주 AI 분석: 공통 KIS 시장 입력에 거래금액순 후보 원천을 추가한다. 섹션별 기존 매매 의도·재료·재무·수급 검증을 거쳐야 하며 거래대금 순위만으로 편입하지 않는다.
- 다섯 섹션 공통: 실제 거래대금 판정 전에 30개로 자르던 제한을 제거한다. 저장 분석→홈과 종가매매→홈의 30개 제한도 제거한다. 기존 섹션별 거래대금 기준과 순위 가점은 유지한다.
- 네트워크 15초 예산은 유지한다. 공급자 순위 API 최대 반환 수, 주도주 별도 수급 검색 범위, AI 입력 범위 제한이 있으므로 시장 전체를 무제한 검사한다고 주장하지 않는다. 시간 예산 초과/자료 부족은 통과가 아니며 미확인으로 기록한다.

## 운영 수집

`ConditionCaptureStore`가 다음 시장 자료를 `backend/data/condition-captures/YYYY-MM-DD.jsonl`(프로세스 작업 디렉터리 기준 기본 `data/condition-captures`)에 저장한다.

- KIS 일봉 원본 응답: 실제 `acml_tr_pbmn`, 일봉 가격·거래량, 조회 시각.
- 섹션 입력 후보, 거래대금 판정 PASS/FAIL/UNKNOWN, 선택 결과, 동일 입력에서 구형 30개 제한을 적용한 결과 코드. 전체 구형 전략의 재현과는 구분한다.
- 단타 네 가지 원천 목록과 검증 전후 목록, 실제 게시 목록.
- 다섯 섹션 최종 게시 목록의 원천 상태·원천 시각과 관측 시각. 오래된 저장 결과의 시각을 새 실시간 포착 시각으로 바꾸지 않는다.
- 종가매매 원천 JSON을 보관해 신호 원천에 존재하는 생성일/갱신일을 보존한다. 존재하지 않는 최초 생성 시각은 만들지 않는다.
- 기존 `AnalysisEvidenceJournalService`의 재무·수급·재료/검증 숫자 근거 기록은 유지한다. 이번 수집이 미확인 뉴스나 재무를 완전하게 복원한다고 주장하지 않는다.

기존·새 선택 종목은 재시작 가능한 watchlist에 보관한다. 정규장에는 3분마다 20초 예산/최대 60종목의 KIS 분봉을 순환 수집한다. 최대 500종목, 마지막 선정 후 35일 추적, 원본 기록 60일 보존, 일일 파일 128MiB 상한이다. 공급자 오류·시간 예산·순환 범위 때문에 분봉은 부분 수집일 수 있으며 `PROVIDER_MINUTE_BARS_PARTIAL_COVERAGE`와 시도 수를 기록한다. 수집 자료의 날짜·체결 시각·포착 이후 여부를 확인한 후 성과에 사용해야 한다. 당일 일봉 고가를 장중 포착 후 최고가로 대체하지 않는다.
