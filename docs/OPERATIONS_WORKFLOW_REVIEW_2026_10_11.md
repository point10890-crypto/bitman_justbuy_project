## 검증 범위

- 회귀 테스트는 분리된 H2, jsdom, 네트워크/알림 mock 및 임시 배포 파일을 사용한다. 테스트를 위해 운영 회원의 신청·결제·승인·비밀번호·텔레그램 데이터를 변경하지 않는다.
- MiniPC 운영 DB, `.env`, JWT 비밀은 유지하고 배포 전 DB/JAR 백업을 사용한다. 스키마 마이그레이션은 추가하지 않는다.
- 기존 작업 중인 시장 데이터, crypto 변경 및 작업과 무관한 미추적 파일은 커밋에서 제외한다.
- 현재 턴의 Computer Use가 Windows 브라우저 URL을 정책 적용에 충분한 확신으로 판별하지 못해 종료됐다. 이후 UI 자동화 우회는 시도하지 않았다. 실제 회원/관리자 브라우저 DOM, 사용 중인 PWA 저장소 및 클릭 흐름은 **완전 검증하지 못했다**. 컴포넌트 테스트와 배포 자산/HTTP 확인은 실제 브라우저 검증을 대신하지 않는다.
