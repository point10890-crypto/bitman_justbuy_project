# KIS 메인·키움 보조 및 스윙·주도주 게시 점검

사용자 선택은 KIS 메인을 유지하고 키움 REST API로 부족한 부분을 보완하는 것이다. 다른 앱의 키나 계정 설정은 가져오지 않는다.

## 기존 미게시 증거

- 08:50 스윙 REVERSAL_EDGE와 주도주 FLOW_LEADER 모두 ChatGPT·DeepSeek 2/2 응답 성공, 후처리 제거·저장·발송은 0건이었다.
- 관리자 시스템 상태에서 두 실행의 결과가 `추천 없음`임을 직접 확인했다. 기존 전일 저장픽은 출처·검증시각이 없어 현재 검증픽으로 복원하지 않는다.
- FLOW_LEADER 지시문이 비활성 Grok 검색 결과만 수급 근거로 요구했고, REVERSAL_EDGE도 Grok 의존 조합을 요구했다. 실제 KIS/Naver/DART 및 확인된 자료를 사용하도록 충돌을 제거했다.
- 응답 성공 수는 파싱·후보 검증·시세 확인·최종 게시 수와 다르다. 새로운 `[PublicationGate]` 로그는 빈 stocks, JSON/스키마 오류, 후보 범위 이탈, 시세·이름 미확인과 최종 게시 수를 구분한다. 원 응답·키·계정·수신자 정보를 기록하지 않는다.
- 최종 EMPTY를 스케줄 로그에도 명시한다. 실제 후보가 없으면 기존 정상 캐시를 보존하며 종목을 임의로 채우지 않는다.

KIS에서 AVAILABLE인 기술·밸류에이션·확정 일별 수급 그룹에는 키움 추가 조회를 하지 않는다. 그룹 단위 보완이며 같은 그룹 안의 개별 필드 병합은 구현하지 않았다. 날짜 미상 장중 가집계를 확정 일별 수급으로 취급하지 않는다. DART·ECOS·기존 KIS 경로와 API 계약은 유지한다.

키움은 후보를 새로 만들어 내거나 기존 확정 가격을 덮어쓰지 않는다. 최종 가격 보완은 기존 후보 코드·정식명·KIWOOM_REST 출처·양수 정수 원화 가격·조회시각을 재검증한다. 실패 시 미확인 가격을 LLM 가격으로 대신하지 않는다.

서비스는 4개 조회 TR와 토큰 발급만 허용한다. 주문·계좌 호출은 없다. HTTPS 고정 도메인, 비공개 토큰 캐시, 전역 초당 5회 이하, 12초 배치 예산, 512KiB 응답 제한을 적용한다. 인증 통신 실패는 30초 공통 cooldown을 사용한다.

키움 거래대금 백만원은 원화로 변환한다. 가격의 등락 부호와 실제 가격을 구분한다. 원 거래시각·시장·재무 관측일이 제공되지 않으면 미확인으로 유지한다. 일봉 날짜가 빠진 경우 연속 구간만 계산하고 부족한 MA20/60·돌파 지표를 제공하지 않는다.

## 직접 설정할 항목

로컬 `backend/.env`에 BitMan 전용 `KIWOOM_APP_KEY`, `KIWOOM_APP_SECRET` 입력란을 준비했다. 이 파일은 Git ignore이며 키는 채팅·커밋·문서에 넣지 않는다. 운영 MiniPC에 설치된 환경 파일은 별도로 보존한다.

- 실제 API 호출 서버인 MiniPC의 공인 출발 IP를 키움 REST 사용신청 화면에 허용 IP로 등록한다.
- 유료 회원 앱·Telegram의 시세·파생 분석 제공에 적용되는 정보이용 조건을 확인한다. 키 발급만으로 재배포 권한이 확인됐다고 기록하지 않는다.
- 운영 활성화는 설정과 이용 범위 확인 후 `BITMAN_KIWOOM_SUPPLEMENT_ENABLED=true`, `BITMAN_KIWOOM_SUPPLEMENT_LICENSED=true`로 진행한다. 기본값은 false이다.
- 관리자 시스템 상태의 `키움 보조 근거 (KIS 우선)`은 비활성/키 미설정/권한 확인 필요/설정 완료를 구분한다. 설정 완료와 실제 API 연결 성공을 구분한다.

공식 자료: [API 가이드](https://openapi.kiwoom.com/guide/apiguide), [신청·키·허용 IP 안내](https://openapi.kiwoom.com/intro/serviceInfo), [운영 제한](https://openapi.kiwoom.com/intro). 공식 샘플을 복사하지 않고 공개된 프로토콜에 맞춘 독립 Java 어댑터로 구현했다.
