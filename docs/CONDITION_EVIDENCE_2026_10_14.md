# 종목별 검출 근거

홈의 5개 섹션에서 종목을 누르면 저장된 근거를 바로 펼친다. 추가 AI 호출은 별도 버튼으로만 시작한다.

`ConditionSignalDto.conditionChecks`는 기존 필드에 추가된 선택적 계약이다. 각 항목은 id, category, criterion, status(PASS/FAIL/UNKNOWN), observedValue, source, observedAt으로 구성된다. 구버전 결과·원천 누락은 UNKNOWN이며, 일반 조건 이름이나 AI 문장을 PASS로 변환하지 않는다.

- 거래대금: 기존 KIS 실제 거래대금 필터가 통과시킨 값, 평균/최소 기준, 정렬 가점, 원천 관측일과 조회 시각을 반환한다. 조회 시각은 최초 종목 포착 시각과 구분한다.
- 기술: 단타 KIS 당일 등락률과 종가 V2 저장 등락률이 있을 때 해당 범위만 판정한다. 정배열, VWAP, 체결강도 등 별도 관측값이 없는 조건은 UNKNOWN이다. 범위 미충족은 설명용 부분 판정이며 새 탈락 규칙이 아니다.
- 재료·재무·수급: 구조화된 원문 관측값이 없는 현재 경로는 개별 조건과 UNKNOWN을 표시한다. 기존 분석/엔진 설명은 별도의 접힌 참고 영역에 보존한다. AI 해석이나 5일 수급으로 당일/20일 조건을 통과 처리하지 않는다.
- 누락된 시간은 현재 시각으로 대체하지 않는다. 실시간 등락률의 시간은 신호 판정 시각, 종가 결과는 원본 신호 기준 시각이다.
- 미구독 응답은 원본 checks를 복사하지 않으며, 클라이언트도 상세 영역을 노출하지 않는다.

조회/판정 UI만 추가한다. 별도 외부 호출, 주문, 메시지 전송은 추가하지 않는다. 위험·무효화 조건을 함께 표시한다. 검출된 후보가 요청된 모든 조건을 통과했다는 의미는 아니다.

검증: API 직렬화/중복 필터 idempotence/미확인 보존, 5개 모드 조건 목록, 관측값 범위·누락, UI 상태·출처 표시, 홈 클릭 시 AI 미호출 및 명시적 추가 분석, 전체 백엔드·프론트엔드 테스트와 빌드.
