## 문제와 수정

1. `PARTIAL`은 조회 범위 제한·시각 미확인·선택적 교차 조회에서도 발생했다. 이를 필수 수급의 현재 대기로 취급하던 표시를 수정했다.
2. 필수 투자자 수급을 확인한 종목, 실제 작업 대기 종목, 자료 미확인 종목을 별도로 집계한다. 완료된 조회가 자료 부족 때문에 계속 진행 중으로 표시되지 않는다.
3. 진행 조회는 처음 검증한 후보·가격·범위·기술/재무 판단 시점을 고정한다. 확인된 수급도 보존하여 캐시 퇴출이나 시간 경과로 기존 결과가 사라지지 않는다.
4. 최종 화면 검증에서 최초 조회의 선택적 KIS·키움 대기 경고가 완료 후에도 현재 진행형으로 남는 문제를 발견했다. 수급 검색에서는 **최초 검색 당시의 상태**라는 과거 기록으로 구분한다. 비수급 검색의 기존 경고는 유지한다.
5. 별도 수급 조회의 기본 결과 상한 10종목이 최종 결합 상한처럼 보였다. `수급 조회 결과 최대 N종목`과 `최종 결합 결과 최대 N종목`을 구분한다. 원래 API의 조회 범위를 바꾸어 표시하지 않는다.
6. 명시한 결과 개수를 모델 응답이 덮어쓰지 않도록 예방 가드를 추가했다. `3개월`, `2개국`, `2개사`, `3개 거래일/영업일`은 결과 개수로 사용하지 않는다. 서로 다른 여러 개수를 제시하면 기존 해석을 유지한다.
