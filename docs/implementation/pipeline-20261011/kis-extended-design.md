# KIS extended evidence design

Prepared during the repair gate; no production expansion or actual KIS request yet. KIS usage rights remain unconfirmed, and the feature defaults to disabled. The coordinator owns YAML flags and the existing orchestrator integration.

`KisExtendedEvidenceService.fetchFormattedExtendedEvidence(List<String>)` will accept at most five distinct six-digit deterministic candidate codes. Disabled mode returns explicit unavailable context before token/request work. Each batch has an approximately eight-second deadline, short dedicated HTTP timeouts and interrupt checks around the shared REST throttle and each request. Old provider/AI HTTP clients and KisApiService's existing three-argument constructor remain compatible. Empty, partial, malformed, stale and provider-error outcomes remain distinguishable.

Minute endpoint: `/uapi/domestic-stock/v1/quotations/inquire-time-itemchartprice`, TR `FHKST03010200`; market `J`, stock code, current Korean input time, past-data `Y`, other-class blank. Official response rows carry `stck_bsop_date`, `stck_cntg_hour`, OHLC prices, `cntg_vol` and `acml_tr_pbmn`. Keep at most thirty valid current-day rows, remove duplicate/future rows and the latest incomplete minute before aggregating. Preserve actual source dates/times and local fetchedAt. Aggregate coverage includes first/last completed minute and row/volume counts. If a weighted close proxy is returned, label it as the recent completed-minute close/volume weighted average; it does not represent full-session VWAP. [Official minute function](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_time_itemchartprice/inquire_time_itemchartprice.py), [official minute field check](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_time_itemchartprice/chk_inquire_time_itemchartprice.py).

Program endpoint: `/uapi/domestic-stock/v1/quotations/program-trade-by-stock`, TR `FHPPG04650101`; market `J`, six-digit code. The official check names `bsop_hour`, `stck_prpr`, `acml_vol`, `whol_smtn_ntby_qty`, `whol_smtn_ntby_tr_pbmn`, corresponding buy/sell volume/amount totals and their deltas. Retain bounded, validated rows and explicit units. That example supplies a time field but no business date: do not create observationDate from the machine's current date. Preserve provider time and capture time separately, with unavailable business-date freshness where needed. No unverified program observation may increase a rule score. [Official program function](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/program_trade_by_stock/program_trade_by_stock.py), [official program field check](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/program_trade_by_stock/chk_program_trade_by_stock.py).

Fixture-first checks will cover disabled/no-provider calls; code/candidate/row bounds; request endpoint/TR/parameters; missing/nonzero provider status; valid current-day complete bars; invalid price/volume/date/time; partial output; absent program business date; batch deadline/interruption; and source/capture/coverage text. The coordinator connects this context before Round 1 using the same selected deterministic candidates, while preserving publication and quote gates.
