# 파이프라인 수정 및 무료·저비용 확장 구현 결과

2026-10-11. 오류 수정을 먼저 완료하고 기존 Spring/Vite 경로에 KIS·DART 증거와 ECOS 시장 문맥을 추가했습니다. 신규 데이터 기능은 모두 기본 비활성이며, 기존 운영 키와 회원 DB를 수동 수정하지 않았습니다.

- 가격: 퍼센트를 가격으로 해석하는 오류를 차단하고, 없는 목표가·손절가는 미확인으로 유지합니다. 최초 포착가·시각을 보존하고 실제 완료된 거래일 관측으로 성과를 계산합니다. 홈페이지의 측정 집계 시작일은 기본 2026-10-12이며 과거 DB 기록은 보존합니다.
- AI: 검증된 후보 코드·명칭·현재가와 출처가 없는 종목은 게시하지 않습니다. 중복 투표, 빈 응답·잘못된 형식, 공급자 타임아웃을 구분하고 전체 실행 시간과 실제 진행 중인 HTTP 요청 수를 제한합니다. 오류에 키·요청 URL을 노출하지 않습니다.
- 운영: 최종 검증 결과만 원자적으로 저장하고 저장 실패·추천 없음 시 기존 정상 결과를 보존합니다. 비동기 작업 소유권, 실행 중 갱신 중복 방지, 실패 단계만 재시도, 알림 전송 확인과 관리자 수동 갱신 무알림 처리를 적용했습니다.
- 확장: KIS 공식 상승률 순위와 제한된 분봉·프로그램 수급, DART 주요 공시·안전한 원문 XML, ECOS의 환율·국고채 3년·기준금리 문맥을 구현했습니다. 날짜·단위·조회 범위·부분 결과·미확인 값을 보존하며 새로운 데이터 문맥 자체가 추천 후보를 만들지 않습니다.
- 관리자: 신규 데이터 소스의 설정·키 준비 상태와 분석 완료·부분 완료·추천 없음·실패를 표시합니다. 키 존재 여부는 실제 API 연결 성공을 뜻하지 않습니다.

## 검증

최종 Gate B: 백엔드 73개 테스트 클래스 / 472개 테스트, 실패·오류·스킵 0. 프론트엔드 19개 파일 / 164개 테스트 및 Vite 빌드 성공. DART 45개, ECOS 19개, 실제 분석 문맥 통합 4개 등 회귀·계약 검증을 포함합니다. 독립 리뷰 지적은 실패 재현 후 수정했고 남은 차단 사항은 없습니다.

새 JAR을 임시 작업 폴더·메모리 H2·가상 관리자·API 키 없는 환경에서 실행해 브라우저 로그인, 홈페이지 측정 집계, 관리자 시스템 상태, 빈 성과 화면을 확인했습니다. 로컬 예약 분석·시작 시 백필·외부 알림은 비활성으로 검증했습니다. JS `index-C06jIWM-.js`, 서비스 워커 `bitman-v20261011-pipeline-integrity-r6`입니다. 검증 후 임시 서버는 종료했습니다.

## 운영 릴리스 검증

구현 커밋 `eeb5f9616ac942976a98cacd34c1e7f7c978b6c4`을 `origin/main`에 푸시하고 원격 SHA 일치를 확인했습니다. 배포 스크립트에서도 백엔드 472개 테스트를 재실행해 통과한 뒤 MiniPC JAR 교체·서비스 재시작을 완료했습니다. 운영 DB와 기존 자격정보는 보존했고 배포 직전 백업을 만들었습니다.

MiniPC의 기존 IP가 변경되어 `minipc-nqylp` 호스트 이름을 사용합니다. 저장된 기존 서버 키를 `HostKeyAlias`로 계속 검증했으며 호스트 검증을 해제하지 않았습니다. static 배포는 새 index/서비스 워커를 덮어쓰고 기존 해시 자산을 보존합니다.

**남은 운영 검증:** 브라우저는 로그아웃 상태였고 운영 관리자 자격정보를 읽거나 사용하지 않았으므로, 보호된 홈페이지·시스템 관리 화면의 운영 DOM은 미검증입니다. 로그인 확인 요청은 전달했으며 로컬 화면 검증과 운영 동일 자산 검증을 실제 운영 로그인 검증으로 대체했다고 주장하지 않습니다. 신규 KIS/DART/ECOS 실응답 검증은 각각 권한·키·캐시 준비 후 활성화 단계에서 수행합니다.

## 사용자가 직접 해결할 부분

1. KIS 유료 회원용 표시·저장·AI 입력 사용 권한을 한국투자증권에 확인합니다. 현재 답변은 **확인 필요**입니다. 신규 KIS 기능은 권한과 실제 응답 확인 후 활성화합니다.
2. ECOS 인증키를 발급하고 MiniPC 서버의 `ECOS_API_KEY`에 직접 설정합니다. 현재 답변은 **아직 없음**입니다. 키를 채팅·Git·프론트엔드에 넣지 않습니다.
3. AI 공급자의 잔액·결제·계정 제한이 있는 경우 해당 공급자 콘솔에서 해제합니다. 코드·오프라인 테스트는 실제 계정 상태를 증명하지 않습니다.

절차와 공식 링크는 [사용자 설정 안내](user-setup.md), 세부 검증은 각 작업 보고서에 기록했습니다. Brave 뉴스 검색은 선택 사항으로 계약상 앱 사용·지속 저장 범위와 키가 준비되기 전까지 구현을 유보합니다.

실제 KIS/DART/AI 키를 사용한 신규 외부 요청은 검증 중 실행하지 않았습니다. DART 신규 기능도 기본 비활성이며 운영에서 최신 기업코드 캐시와 실제 원문을 확인한 뒤 활성화합니다. 과거 성과 수치를 추정으로 교정하거나 회원 DB를 수동 백필하지 않았습니다. 보호된 운영 화면은 관리자 로그인 후 별도 확인이 필요합니다.
