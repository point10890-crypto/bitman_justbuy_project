# 신규 분석 데이터 활성화에 필요한 사용자 확인

코드 오류 수정에는 신규 계정이나 키가 필요하지 않습니다. 신규 데이터 기능은 아래 확인이 끝날 때까지 기본 비활성 상태로 준비합니다. 키 값은 채팅, Git, 공지 게시판에 올리지 않습니다.

## 1. KIS 유료 회원 앱 사용 권한 — 확인 필요

한국투자증권에 다음 사용 형태를 설명하고 제휴·정보 이용 범위를 서면으로 확인합니다: **BitMan 유료 회원용 웹/PWA에서 국내주식 시세, 상승률/거래량 순위, 종목별 분봉과 프로그램 수급을 분석하고 결과를 회원에게 표시·보관하는 서비스**. AI 모델 입력과 분석 결과의 재배포/저장 범위도 함께 확인합니다. 개인 계좌용 OpenAPI 키 보유만으로 제3자 서비스 권한을 확보했다고 간주하지 않습니다.

공식 안내: [KIS 제휴 안내](https://apiportal.koreainvestment.com/provider), [공식 API 예제](https://github.com/koreainvestment/open-trading-api).

기존 KIS 설정은 보존합니다. 신규 분봉/프로그램 증거 기능의 운영 활성화는 권한 확인 이후 `BITMAN_KIS_EXTENDED_EVIDENCE_ENABLED` 설정과 실제 응답·호출량 검증을 거쳐 진행합니다.

## 2. 한국은행 ECOS 인증키 — 아직 없음

[한국은행 ECOS OpenAPI](https://ecos.bok.or.kr/api/)에서 인증키 신청을 완료합니다. 발급받은 키는 MiniPC 서버의 기존 환경 설정에 `ECOS_API_KEY`로 직접 설정합니다. 프론트엔드 환경변수에 넣지 않습니다.

설정 후 `BITMAN_ECOS_ENABLED=true`로 활성화하고, 원/미국달러 매매기준율·국고채 3년·한국은행 기준금리의 관측일과 단위가 실제 응답과 일치하는지 확인합니다. 일별 공표 통계이며 실시간 시세나 공표 시각을 임의로 만들지 않습니다. [통계정보 이용 안내](https://www.bok.or.kr/portal/main/contents.do?menuNo=200228)에 따라 출처와 가공 여부를 표시합니다.

## 3. 별도 뉴스 API — 선택

Brave Search는 필수 연동이 아닙니다. [공식 상품](https://brave.com/search/api/)과 [이용약관](https://api-dashboard.search.brave.com/documentation/resources/terms-of-service)을 확인한 뒤, 유료 앱과 AI 입력 및 **지속 저장**이 허용되는 계약 범위를 먼저 확보합니다. 일반 검색 요금만으로 검색 결과·스니펫을 DB나 분석 캐시에 장기 보관할 수 있다고 간주하지 않습니다. 가입·결제·키 발급은 사용자 작업이며, 승인된 범위가 없으면 비활성 상태를 유지합니다.

## 4. DART 신규 공시 증거 기능 — 활성화 전 검증

기존 DART 키 설정을 재사용하며 새 키 발급은 필수가 아닙니다. 신규 기능은 `BITMAN_DART_EVENT_EVIDENCE_ENABLED=false`가 기본값입니다. 운영 활성화 전 최신 기업코드 캐시 준비 상태와 실제 공시 응답을 확인하고, `true` 설정 후 전환사채·유상증자·자사주·원문 추출의 접수번호, 정정 여부, 날짜와 단위를 대조합니다. 확인할 수 없는 필드는 미확인으로 남깁니다. 이 준비는 서버 작업으로 진행하며 키를 채팅으로 전달할 필요는 없습니다.

## 운영 검증의 범위

오프라인 HTTP fixture 검증은 API 계약·오류 처리·출처 보존을 검증합니다. 실제 키의 권한, 잔액, 호출 한도, 한국어 뉴스 품질을 증명하지는 않습니다. 운영 활성화 후 실제 응답 검증이 별도로 필요합니다. 기존 AI 공급자의 결제/잔액/계정 차단 문제가 확인되면 해당 공급자 콘솔에서 사용자가 해제해야 하며, 코드는 실패와 부분 성공을 명시합니다.
