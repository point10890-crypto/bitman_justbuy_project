# 모바일 퍼블리싱

- 600px 이하: 홈·조건검색·알림·마이·더보기 5개 하단 메뉴. 기존 데스크톱 메뉴 유지.
- 5개 섹션 가로 이동, 작은 로봇 영역과 검색창, 큰 종목명과 3개 가격 지표를 2행으로 배치.
- 가격 칸에 섹션별 레이블을 함께 표시. 긴 종목명과 큰 가격을 줄바꿈하며 가로 넘침 방지.
- 검출 근거는 분야별 details/summary. 거래대금만 기본 펼침, 다른 분야는 펼쳐서 확인. 판정 로직 변경 없음.
- 모바일 본문 14~16px, 주요 터치 영역 최소 44px, 기기 하단 안전영역 및 키보드 포커스 표시.
- 더보기는 스크롤 가능한 하단 패널. 배경이 클릭을 막지 않도록 레이어 분리. Escape 닫기·트리거 포커스 복원.
- 알림 안내에 닫기 버튼 추가. 메뉴가 열리면 알림 안내 숨김.

로컬 검증은 외부 요청을 모두 차단한 임시 예시 데이터 화면으로 진행하고 해당 파일은 삭제했다. 360/390/430px에서 문서 가로 넘침 및 가격 셀 잘림 0건. 1280px에서 기존 4열 표와 데스크톱 하단 메뉴 확인. 모바일 더보기 → 마이 → 홈 이동 확인.

회귀 테스트: 전체 프론트엔드 테스트·빌드, 배포 스크립트의 전체 백엔드 테스트. 운영 반영 후 실제 로그인된 홈에서 모바일 화면과 근거 펼치기 확인.
