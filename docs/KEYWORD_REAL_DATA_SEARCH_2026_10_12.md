# 키워드 실데이터 조건검색

홈 검색창은 `/api/analysis/keyword-search`로 원문 조건을 보내고 실제 시세에 숫자 조건을 AND로 적용한다. 기존 종목·테마 AI 분석 버튼은 별도 흐름을 유지한다. 검색 결과를 AI 생성 종목, 분석 캐시, 예시 데이터로 채우지 않는다.

## 지원 범위

- 현재가, 등락률, 거래량, 거래대금의 이상·이하·초과·미만·같음 조건
- 코스피/코스닥, 종목명 포함, 6자리 종목코드 직접 조회
- 거래량·거래대금·등락률 상위 정렬, 최대 20개 표시
- 외국인/기관 순매수, 쌍끌이, 최근 1~10거래일의 실제 수급 관측

예: `코스피 현재가 5만원 이하 상승률 3% 이상 거래대금 100억 이상`

일반 조회는 NAVER_FINANCE의 코스피·코스닥 시가총액 상위 각 200종목, 최대 400종목을 검사한다. 전체 상장 종목 검색이 아니다. 직접 코드 조회는 기본 시세만 확보하며 거래량·거래대금 누락값을 추정하지 않는다. 수급은 시세 조건 통과 후 정렬된 최대 20종목에 기존 KIS 투자자별 매매 조회를 적용한다.

뉴스·공시·테마 관련주·급증·신고가·저평가·OR 등 근거 수집이 구현되지 않은 조건은 미지원으로 안내하며 일부 조건을 생략해 실행하지 않는다.

## 데이터 경계

- Naver 원 단위 `accumulatedTradingValueRaw`만 거래대금으로 사용한다. 화면용 축약 숫자와 가격×거래량을 대신 사용하지 않는다.
- 원본 거래 관측 시각과 조회 시각을 분리한다. 휴장 중 이전 거래일 시세를 오늘 시세로 변경하지 않는다.
- 수급은 성공 응답·실제 날짜·정확한 요청 관측 수·중복/미래/휴장일·정수 수량·합산 오버플로를 검증한다.
- 조건 또는 명시 순위에 필요한 실측값이 없으면 해당 행을 제외한다. 정상 0건, 부분 결과, 조회 불가, 미지원 요청을 구분한다.
- 시세 조회와 수급 조회는 각각 최대 20초 예산이다. 합산 최대 약 40초이며, 짧은 HTTP 제한과 최대 4개 동시 검색을 적용한다.
- 시세 캐시 30초는 원래 조회·관측 시각을 보존한다. 수급은 키워드 경로에서 180초 이내 원래 조회 시각만 허용한다.
- PRO 인증 가드는 유지하고 AI 호출/분석 작업 생성/알림 전송/검색결과 저장을 하지 않는다.

## 운영 전제

키워드 검색은 기존 공개 시세 및 기존 KIS 수급 조회 경로를 사용한다. 신규 KIS 확장 근거와 DART 이벤트 근거 플래그는 이 변경으로 켜지 않는다. KIS 회원 서비스 이용 권한은 사용자 확인이 필요하다.

사용자가 개발 PC의 `backend/.env`에 ECOS 키를 직접 저장했다. 키를 출력하지 않고 공식 ECOS에서 환율·국고채 3년·기준금리 3개 일별 통계의 2026-10-08 관측 자료를 검증했다. MiniPC에는 ECOS 키·활성화 플래그 두 항목만 반영하고 기존 환경설정과 회원 DB를 보존한다. ECOS는 공표 통계 문맥이며 주가·종목 후보를 대체하지 않는다.
