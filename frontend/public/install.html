BitMan 앱 설치

오늘 뭐사? · 홈 화면에서 바로 실행

별도 APK 파일 없이 브라우저에서 설치하는 웹앱입니다. 이 설치 페이지는 로그인 없이 이용할 수 있습니다.

휴대폰에 설치하기

안드로이드는 Chrome에서 이 페이지를 열어 주세요.

Chrome에서 설치 페이지 열기
  1. 카카오톡·네이버 앱 안에서 보고 있다면 메뉴의 다른 브라우저로 열기를 선택합니다.
  2. Chrome에서 앱 설치하기를 누릅니다. 버튼이 없으면 오른쪽 위 ⋮ → 홈 화면에 추가 → 설치를 선택합니다.
  3. 설치 확인 후 홈 화면의 BitMan 아이콘으로 실행합니다.

iPhone은 Safari의 공유 메뉴 → 홈 화면에 추가를 이용하세요.

실행이 안 될 때

아래에서 웹으로 먼저 열어 보세요. 웹은 열리는데 설치된 앱만 멈춘다면 앱을 완전히 종료하고 Chrome을 업데이트한 뒤 다시 실행해 주세요.
